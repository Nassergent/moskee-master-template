```typescript
export async function verifyHmacTimingSafe(
  secret: string,
  body: string,
  signatureBase64: string
): Promise<boolean>;
```

The function uses `crypto.subtle.importKey` + `crypto.subtle.verify` (Web Crypto API, available in Node 18+). It:
1. Imports `secret` as an HMAC-SHA256 key
2. Decodes `signatureBase64` from base64 to Uint8Array
3. Calls `crypto.subtle.verify('HMAC', key, signatureBytes, encoder.encode(body))`
4. Returns boolean — inherently timing-safe (no string comparison)
