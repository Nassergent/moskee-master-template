# Plan 02-01: HMAC Verificatie Losgekoppeld van API Key Format

## Context

`mollie-webhook.ts:30` checkt `mollieKey.startsWith('test_')` om HMAC te skippen. Dit is fragiel: als iemand per ongeluk een test key in productie zet, wordt HMAC overgeslagen. Bovendien checkt `webhook-service.ts:64` op `mollieKey === 'test_xxxxxxxxxxxx'` (exact match) voor demo mode — twee verschillende patronen voor hetzelfde concept.

## must_haves

1. HMAC skip gecontroleerd door env var, niet API key format
2. Skip gelogd als ERROR level
3. Demo mode in webhook-service ook via env var

## Tasks

<task id="2.1" title="Replace HMAC skip logic in mollie-webhook.ts">
**File:** `src/pages/api/mollie-webhook.ts`

Replace lines 30-32:
```typescript
// OLD:
if (mollieKey.startsWith('test_')) {
  console.warn('[webhook] HMAC verification skipped (test mode)');
}

// NEW:
if (import.meta.env.WEBHOOK_SKIP_VERIFICATION === 'true') {
  console.error(formatLog('error', 'hmac_verification_skipped', { route: '/api/mollie-webhook' }));
}
```

Import `formatLog` from `../../lib/logic/logger`.
</task>

<task id="2.2" title="Update demo mode check in webhook-service.ts">

// OLD:
if (!mollieKey || mollieKey === 'test_xxxxxxxxxxxx') {

</task>
